## 3. 결과 모양
- 판정 로직과 화면 표시는 파일을 나눈다 (Assets/_Project/Game/Bake)
- 빵 데이터는 data_bread 표 설계대로 Assets/_Project/Data에 만들고, 숫자는 여기서만 읽는다
- 화면은 임시 리소스(단순한 도형, 기본 UI)로 충분하다
- 하지 말 것: 판매, 코인, 레벨업 기능까지 만들지 말 것

## 4. 지어내기 금지
표와 문서에 없는 숫자나 규칙을 코드에 직접 쓰지 말고, 필요하면 [자료 없음: 필요한 것]으로 표시해 줘.

## 5. 스스로 확인
통과 조건 4줄마다 맞음 / 틀림을 적고, 자신 없는 곳엔 ★와 이유를 달아 줘.
