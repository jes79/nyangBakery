# 통과 조건: 굽기 타이밍 판정
- 관련 결정 카드: bake_timing_rule_v2

## 통과 조건
- 플레이어가 이렇게 하면: 굽는 중인 오븐을 탭한다
- 게임이 이렇게 하고: 진행 막대 위치로 덜 익음 / 딱 좋음 / 탐을 판정한다
- 이게 보이면 통과: 딱 좋음이면 초록 표시와 보너스 가격이 뜬다
- 이럴 때는 예외: 너무 일찍 누르면 덜 익은 빵, 딱 좋은 구간이 끝날 때까지 안 누르면 자동으로 탄 빵. 둘 다 가격이 절반 (bake_rules)

## 느낌을 숫자로
- 원하는 느낌: 노릇해지는 순간이 살짝 긴장되게
- 고른 숫자: 딱 좋은 구간 0.6초 (data_bread의 perfect_window)
- 직접 해 봐야 아는 것: 휴대폰 터치 지연, 한 손 플레이 난이도
