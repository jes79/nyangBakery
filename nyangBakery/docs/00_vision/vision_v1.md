# 게임 방향 1장 (vision_v1) · 확정

## 핵심 손맛 한 줄
플레이어는 오븐 속 빵이 노릇해지는 순간을 보고 딱 맞게 꺼낼 때 재미있다.

## 1. 어떤 게임인가
- 장르: 캐주얼 성장 (가게 운영)
- 기기: 모바일 세로 화면
- 한 판 시간: 3분

## 2. 누가 하나
- 귀여운 게임을 좋아하는 직장인
- 출퇴근길, 잠깐 쉴 때 (한 손 플레이)

## 3. 뭐가 다른가
- 자동으로 돌아가는 가게 게임이지만 굽기 타이밍은 직접 맞춘다
- 고양이 제빵사가 레벨업하며 새 빵을 배운다

## 4. 고민될 때 기준
- 짧게 해도 손해 보지 않게
- 숫자가 오르는 재미보다 굽는 손맛이 먼저
- 귀여움을 해치지 않게

## 5. 하지 않을 것
- 광고를 억지로 보게 하지 않는다
- 복잡한 전투를 넣지 않는다
- 매일 접속을 강요하지 않는다

## 이번에 만들 범위
- 넣을 것: 빵 굽기, 팔아서 코인 받기, 고양이 레벨업
- 나중에: 가게 꾸미기, 빵 도감, 이벤트
