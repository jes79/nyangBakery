# 프로젝트 규칙 (냥이 베이커리)

## 이 게임
- 핵심 손맛: 오븐 속 빵이 노릇해지는 순간을 보고 딱 맞게 꺼낼 때 재미있다
- 게임 방향: docs/00_vision/vision_v1.md

## 환경
- Unity 6, URP, Android 모바일 세로 화면, C#
- 입력은 프로젝트에 설정된 Input System을 확인하고 그에 맞춘다

## 폴더 규칙
- 이 게임만의 코드: Assets/_Project/Game
- 다시 쓸 코드: Assets/_Project/Core (Game을 참조하지 않는다)
- 숫자와 설정값: Assets/_Project/Data
- 임시 리소스: Assets/_Project/Art/Temp, VARCO 원본: Assets/_Project/Art/Varco
- 씬: Assets/_Project/Scenes
- 기획 문서: docs (결정 카드는 docs/01_rules, 표 설계는 docs/03_tables, 통과 조건은 docs/04_pass)

## 작업 방식
- 요청 한 번에 기능 하나만 한다
- 코드를 쓰기 전에 계획을 먼저 보여주고 확인을 기다린다
- 관련 결정 카드를 먼저 읽는다
- 문서에 없는 규칙이나 숫자는 지어내지 말고 [자료 없음: 필요한 것]으로 표시한다
- 끝나면 통과 조건마다 맞음 / 틀림을 적고, 자신 없는 곳엔 ★와 이유를 단다

## Unity 에디터
- 씬과 프리팹은 파일을 직접 고치지 말고 에디터 연결로 수정한다
- 에디터를 조작하기 전에 무엇을 바꿀지 먼저 말하고 확인을 기다린다
- 작업이 끝나면 콘솔에 에러가 없는지 확인한다

## VARCO
- 워크플로는 노드 구성까지만 하고, 실행은 확인을 받은 뒤에 한다
- 후보는 한 번에 3개까지

## 하지 말 것
- 굽는 시간, 판정 구간, 가격 같은 숫자를 코드에 직접 쓰기. 반드시 Data의 표에서 읽는다
- 요청하지 않은 파일 수정이나 삭제, 패키지 설치
- 커밋과 푸시 (사람이 GitHub Desktop에서 확인 후 한다)
